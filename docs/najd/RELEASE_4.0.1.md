# NajdTV v4.0.1

## المشغل
- ترتيب ثابت للأدوات: السابقة، الصوت والترجمة، المزيد، الحلقات، التالية؛ تبقى الخانات غير المناسبة للأفلام فارغة. حُفظت اختصارات المزيد، وأضيفت أدوات سريعة للقفل والجودة والأبعاد والبحث والمواسم وملء الشاشة.
- خلفية عامة شفافة وأزرار ذات إطار وطمس محصور داخل الزر. الوقت داخل شارة سوداء وبصيغة HH:MM:SS.
- صوت يمين وسطوع يسار، والصفر أسفل و100 أعلى حتى مع RTL، مع ارتفاع يتكيف مع المساحة المتبقية.
- نقرتان تفعّلان القفز، ثم كل نقرة تزيد خطوة، مع تأثير في وسط النصف المعني وحفظ الهدف أثناء تأخر المحرك.
- أفضل جودة/مناسبة للإنترنت/أقل جودة تستخدم المستويات أو المصادر المرصودة. يستخدم HLS الأصلي سياسة bitrate في libmpv مع الحفاظ على رابط الماستر ومجموعات الصوت؛ وضع الإنترنت يختار سقفاً من سرعة الكاش المرصودة عند الاختيار، أو سقفاً محافظاً عند غياب القياس. الويب يستخدم تكيف HLS حين يتوفر. لا تُختلق دقة غير موجودة؛ الجودة الواحدة تبقى نفسها في الخيارات الثلاثة.
- توسيع استخراج وتمرير صيغ الفيديو المباشر وفحص تواقيع حاويات إضافية، وإصلاح مسارات كانت تعيد تسمية كل رابط MP4. التشغيل محلي بلا خدمة تحويل مدفوعة وبلا SDK إعلانات أو مشغل طرف ثالث. لا يمكن ضمان كل ترميز على كل متصفح، أو تكلفة بنية تحتية وشبكة تساوي صفراً؛ قد يحتاج الويب مصدراً بترميز متوافق. لا تُزال الإعلانات المحروقة داخل الفيديو.

## الرئيسية والتصفح
- 15 عملاً فريداً كحد أعلى في العرض الدوّار المستمر، مع نقاط واستجابة لحجم الشاشة حتى خمس بطاقات. يحترم تقليل الحركة وتوقف التفاعل/التركيز.
- عرض علوي في أقسام الأفلام والمسلسلات والأنمي والتركي، واختيارات يومية من TMDB.
- 108 سياسات تصفية حقيقية، منها 20 للرئيسية و20 على الأقل لكل قسم؛ ليست ادعاء وجود 108 أنواع رسمية منفصلة في TMDB. تحميل القوائم قرب ظهورها، وإخفاء القوائم ذات المحتوى المتطابق بالكامل.
- أرقام ترتيب أفضل القوائم يسار البطاقة وفي صفحة المزيد، وإخفاء معرّفات catalog التقنية من النص المعروض.
- زر رجوع للأعلى، وفلاتر أعمال الممثل: الأحدث/الأقدم/الرائج والسنة. الرواج يعتمد بيانات popularity الفعلية حين يوفرها TMDB.
