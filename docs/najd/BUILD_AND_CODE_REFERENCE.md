# Build and code reference

Current product version comes from `flutter_app/pubspec.yaml` and the shared version contract. Release notes for the current 4.0.2 release are `RELEASE_4.0.2.md`; release workflows read that versioned path dynamically.

| Responsibility | Source/build input |
|---|---|
| Flutter entrypoint and adaptive navigation | `flutter_app/lib/main.dart`, `app_target.dart`, `ui_contract.dart` |
| Local library, owner synchronization and checkpoints | `library_store.dart`, `cloud_library.dart`, `library_sync_record.dart` |
| Playback and per-open extraction capability | `api_client.dart`, `player_page.dart`, `playback_handoff.dart` |
| Video and controls | `universal_player.dart`, `playback_timeline.dart`, native/web video implementations |
| Library export/import | `library_backup_control.dart`, conditional native/web export implementations |
| Node production entrypoint | `server/index-runtime.mjs`, `server/app.mjs` |
| Independent source families | `server/scrapers/registry.mjs`, `server/browser/registry.mjs` |
| Source catalog and media verification | `server/harvest/`, `shared/content-identity.js` |
| Session credentials | `server/playback-sessions.mjs`, `server/harvest/session-playback.mjs` |
| Edge gateway | `edge/src/router.mjs`, provider workers and `edge/config/` |
| Database | `supabase/migrations/`, `supabase/README.md` |
| Current provider inventory | `docs/providers.json`, generated by `scripts/provider_inventory.py` |

`mobile-trial.yml` builds release targets; `promote-reviewed-release.yml` validates source manifests and publishes reviewed assets. Public and authenticated internal Web bundles have separate entrypoints. Approved design inputs remain under `design/najd-ui/`; license notices remain alongside redistributed assets. Private fonts/signing credentials must not enter Git.

`app/source-manifest.json` is a negative legacy-build fixture required by platform tests, not an application bundle to publish. The retired duplicate `app/` binaries are unnecessary. `docs/legacy/index.html.source` remains a browser-test input.

Use the exact source SHA and actual release checks. A Node/Flutter test pass does not certify an IPA signature, Android update-key continuity, hardware decoding or two physical phones.
